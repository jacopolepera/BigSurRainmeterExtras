# Big Sur Rainmeter - Extras & Updates

This repository is a fork of the popular [BigSurRainmeter](https://github.com/fediaFedia/BigSurRainmeter) skin by **fediaFedia**. 

This version (`BigSurRainmeterExtras`) focuses on expanding the functionality with a few **extra widgets** and specific customizations.

## 🚀 What's New?

This fork adds specific widgets to fill the gaps in the original suite, offering more granular control and task monitoring.

### 🆕 New & Modified Widgets
Compared to the original repository, the following widgets have been added or modified in the `/Widgets` directory:

| Widget Name | Description |
| :--- | :--- |
| **System Monitor** | Added a new variant that includes real-time **GPU monitoring**. |
| **Spotify Player** | Applied UI tweaks and personal preference adjustments to the Big player variant. |
| **Counter** | A versatile counter to track anything. Includes a variant with a **customizable target goal**, ideal for task monitoring. |
| **LightSwitch** | A dedicated toggle switch to control a **Xiaomi Desk Lamp** directly from the desktop. Should be personalized manually changing the URL endpoints |
| **GmailAtomList** | A widget to preview new emails via RSS on Gmail Atom service. Should be personalized by manually changing the Username and using a dedicated App password. More on that at: https://support.google.com/mail/answer/185833?hl=en |


> *Note: Some original widgets may contain minor modifications to ensure compatibility or consistent styling.*

## 📦 Installation

You can download the whole repository and overwrite the old original folder. Alternatively, you can selectively copy the new/modified widgets from the `/Widgets` folder into your existing BigSurRainmeter installation.
